# Code of Conduct

## Scope

This code of conduct applies to Boulder repository issues, pull requests, reviews, documentation, examples, and community discussions connected to the project.

## Expected Behavior

- Be respectful and concrete.
- Critique code, docs, evidence, and decisions, not people.
- Keep changes small enough to review.
- Provide reproduction steps, tests, and evidence when making claims.
- Do not post secrets, tokens, credentials, private repository content, or proprietary logs.

## Unacceptable Behavior

- Harassment, discrimination, threats, or personal attacks.
- Publishing private information without permission.
- Deliberately disruptive comments or repeated off-topic issues.
- Security reports that expose working exploits, secrets, or private data publicly.

## Enforcement

The current maintainer may edit, hide, or remove comments; close issues or PRs; block users; or restrict participation when conduct harms the project or contributors.

For security-sensitive or conduct-sensitive reports, open a minimal public issue that does not expose private details and ask for a private handoff path.
