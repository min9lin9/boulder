# Subagent Recommendations

Suggested Codex subagent roles for Boulder-generated harnesses:

- `code-mapper` for repo orientation
- `reviewer` for PR-style correctness review
- `security-auditor` for scoped security review
- `documentation-engineer` for docs and release notes

External catalogs such as `VoltAgent/awesome-codex-subagents` can be referenced with attribution, but Boulder does not claim ownership or adoption from those projects.
