# Maintainer Workflows

`boulder` supports repeatable Codex-ready maintenance workflows:

- Superpowers workflow spine
- GStack review gates
- Compound learning layer
- issue triage
- PR review prep
- release planning
- dependency review
- verification gates

Each workflow should record context, approval boundaries, command evidence, verification results, and unresolved risks.

## Default Operator Stack

- Superpowers drives brainstorming, planning, implementation, review, and verification.
- GStack inserts CSO, QA, executive, or office-hours gates before risky decisions.
- Compound captures reusable decisions, repeated failure modes, and durable workflow improvements.
